## PROBLEM A

---

### Insurance Claims – Java Program
---
### Problem Statement

Write a Java program to create a class for an Insurance Claims scenario.

Create a "Claim" class with the following attributes:

- "claimId"
- "amount"

The "Claim" class should have a constructor to initialize these attributes.

Create a subclass "MedicalClaim" that extends the "Claim" class and adds the attribute:

- "hospitalName"

Override the "display()" method in the "MedicalClaim" class to display all the claim details.

---

### Assigned Data

Attribute | Assigned Data

Claim ID | 1001

Amount | ₹75,000

Hospital Name| Apollo Hospital

---

## Sample Output

Insurance Claim Details
------------------------
Claim ID      : 1001

Claim Amount  : ₹75000.0

Hospital Name : Apollo Hospital

---

### Result

The program successfully creates a "Claim" class and a "MedicalClaim" subclass, demonstrates inheritance and method overriding, and displays all the insurance claim details.
